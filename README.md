## 📖 项目简介

QuickPandown（快客盘）部署在**一台常开的服务器或电脑**上：

1. 粘贴 `pan.quark.cn/s/...` 分享链接（支持带提取码的链接）；
2. 服务端解析目录树、按需浏览并勾选文件（支持按类型/大小筛选、全选反选、整目录提交）；
3. 下载引擎把选中的文件**转存到用户自己的网盘临时目录**，再自网盘取回、写入服务器 `downloads/` 暂存目录；
4. 任务全程经由 SSE 实时推送进度；**完成后浏览器自动弹出下载**，把文件落到你当前设备——手机、电脑都能无痛收文件。

多用户场景下，每人一个账号（可开启邀请码制），各任务按登录用户隔离互不可见；夸克网盘 Cookie 只保存在**每个人自己的浏览器**里，绝不上传到服务器存储。

```
浏览器 ──登录/解析/勾选──▶ QuickPandown 服务 ──夸克官方 API──▶ 夸克网盘（云端）
   △                              │  │
   │        SSE 实时进度           │  └──引擎：转存临时目录 → 逐文件取回 → 写入 downloads/
   └──────完成自动弹下载 ◀──/api/files/{HMAC token}─（本地 HTTP 直出）
```

## ✨ 功能特点

**用户侧**
- 📎 一键解析：任意文本粘贴提取链接；提取码自动识别（`?pwd=`）；
- 🗂 目录树懒加载浏览，不阻塞界面；支持视频/音频/图片/文档/压缩包类型筛选、按大小过滤、全选/反选；
- 🎯 并发下载引擎（管理员可调 1–10），细粒度子项进度；失败可重试、运行中可取消；
- ⚡ 任务完成后浏览器**自动下载**；
- 📡 SSE 实时进度条与速度/剩余时间估算。

**安全与多用户**
- 🔐 登录墙：argon2 密码哈希、HttpOnly 会话 Cookie（7 天）；
- 🧑 邀请码制注册：邀请码一次性、原子占用，防脚本批量注册；注册/登录带本地签发的 SVG 人机验证码；
- ✉️ 注册邮箱仅接受常用域名（gmail/outlook/qq/foxmail/163/126 等），拒绝任意临时邮箱（**注意：当前暂不支持邮箱验证服务**）；
- 🍪 夸克 Cookie 仅存浏览器 localStorage，经请求头随请求传递，服务器不存储；
- 🛡 下载凭据 HMAC 签名（1 小时有效），绑定会话防盗链。

**管理侧（仅管理员可见/可用）**
- ⚙️ 全局设置：下载目录、并发数、本地文件保留时长、单次下载总量上限、磁盘预留空间；
- 🎫 邀请码管理：生成/删除/查看使用状态；
- 📊 在线统计：在线用户数、正在下载人数；
- 💽 磁盘空间监控：管理页显示已用/剩余空间，可用空间不足时显示警告。

**工程侧**
- 🚫 前端零构建、零 CDN：原生 ES2020，FF 离线可用；
- 🌐 数据库可选择：默认 SQLite，支持 `QP_DB_URL` 覆盖为 MySQL/任意 SQLAlchemy 支持；
- 🔋 断电/重启后任务历史落盘恢复（`data/tasks.json`，终态任务超过 7 天自动修剪；启动时回收未完成下载的 `.part` 残留）。

## 🚀 如何部署

### 环境要求

| 项 | 要求 |
|---|---|
| Python | 3.10+（在 3.10.x 上开发验证） |
| 操作系统 | Windows / MacOS / Linux 均可 |
| 数据库 | 首次启动自动生成 `data/db.json`，默认 **SQLite**；MySQL 长期部署见下 |
| 网络 | 服务器需能**直连**夸克接口（已内置绕过系统代理） |
| 浏览器 | 任意现代浏览器（Chrome/Edge/Firefox） |

### 1. 安装依赖

```bash
cd QuickPandown
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. 准备数据库

数据库来源优先级：**环境变量 `QP_DB_URL` > `data/db.json` 配置文件**。首次启动默认 **SQLite**，同时自动生成 `data/db.json` 模板，要长期部署用 MySQL 需要编辑 `db.json` 文件。

##### 方式 A：编辑 `data/db.json` 用 MySQL（推荐，适合长期部署）

首次启动后（自动生成 SQLite 模板），把 `db_url` 改成你的 MySQL 连接串：

```json
{
  "db_url": "mysql+aiomysql://用户名:密码@127.0.0.1:3306/quickpandown",
  "_comment": "……"
}
```

##### 方式 B：环境变量（优先级更高，适合脚本/容器）

```bash
# Windows PowerShell
$env:QP_DB_URL = "mysql+aiomysql://用户名:密码@127.0.0.1:3306/quickpandown"

# Linux/macOS
export QP_DB_URL="mysql+aiomysql://用户名:密码@127.0.0.1:3306/quickpandown"
```

##### 方式 C：SQLite（首次默认）

首次启动自动生成模板即 SQLite；如需改名/搬位置，把 `db_url` 改成：

```json
{ "db_url": "sqlite+aiosqlite:///quickpandown.db" }
```

> 文件损坏或 `db_url` 非法时自动回退本机 SQLite（`data/app.sqlite3`）。

### 3. 预置管理员（幂等，已存在则跳过）

```bash
python run.py --admin [用户名] [you@gmail.com] [一个足够强的密码]
```

### 4. 启动服务

```bash
python run.py            # 监听 0.0.0.0:8756
```

浏览器打开 `http://服务器IP:8756`（本机则为 `http://127.0.0.1:8756`）。登录后粘贴链接即可使用。

### 5. 修改端口 / 常开部署

- 端口：改 `run.py` 顶部 `PORT`（默认 `8756`，host `0.0.0.0`）。
- 后台跑：Windows 建议 `nssm` / 计划任务，Linux 建议 systemd：
  ```ini
  [Service]
  WorkingDirectory=/opt/QuickPandown
  Environment=QP_DB_URL=mysql+aiomysql://user:pass@127.0.0.1:3306/quickpandown
  ExecStart=/opt/QuickPandown/.venv/bin/python run.py
  Restart=always
  ```
- 反向代理（可选）：正常转发即可；注意真实客户端 IP 参与登录限速，反代后需自行处理 `X-Forwarded-For`。
- Ctrl+C 关停：优雅退出有 5 秒缓冲（浏览器页面挂着 SSE 时也能自动收尾）。

## ⚙️ 配置与数据文件

| 路径 | 说明 |
|---|---|
| `data/db.json`       | 数据库连接串配置（首次自动生成；**含数据库密码，勿外传**） |
| `data/settings.json` | 全局设置（下载目录、并发数、本地保留时长、下载总量上限、磁盘预留空间），管理员设置弹窗维护 |
| `data/tasks.json`    | 任务历史落盘，重启后自动恢复列表；终态任务超过 7 天自动修剪，仍有关联文件的条目保留到文件到期后再留 7 天，保证清扫器始终有据可查 |
| `data/secret.key`    | 文件下载 HMAC 密钥，首次自动生成；**泄露等于下载接口被拓开，勿外传** |
| `downloads/`         | 抓取下来的文件默认落点（可在设置中改），按 `用户名/任务ID/文件路径` 三级存放——同一用户不同任务的同名文件互不覆盖、并发互不踩写；保留时长到点自动清理，清空后的空文件夹一并收拢 |

环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `QP_DB_URL` | 无（优先读 `data/db.json`，首次启动自动生成模板） | 数据库连接串，优先级高于 `data/db.json`（mysql+aiomysql / sqlite+aiosqlite 等） |

## 🍪 使用指南

1. **登录/注册**：使用管理员给的邀请码注册（用户名 + 常用邮箱 + 强密码），使用用户名 + 密码登录；
2. **设置夸克 Cookie**：第一次用会自动弹出 Cookie 设置弹窗；在浏览器登录夸克网页版后按提示复制 Cookie 粘贴（**只保存在你这台设备的浏览器**）。Cookie 失效（提示重新复制）时重粘即可；不同账号/设备互不影响；
3. **解析**：把整段分享文本贴进输入框点「解析」（文本里可以带提取码；没有就填进提取码输入框点「确定」）；
4. **浏览与筛选**：目录树点击展开；按类型/大小筛选；全选/反选/逐项勾选；
5. **下载**：点「下载所选」即时入队进行解析，解析完成后自动开始转存与下载，任务卡实时刷新进度；完成后多文件自动打成一个 ZIP 弹出保存（单文件直接弹出）；如果配置了「单次下载总量上限」，那么下载文件大小超限时会拒绝下载；
6. **失败重试 / 取消**：失败任务点「重试」（解析期失败会重新解析；下载期失败只重跑失败文件）；运行中可「取消」。

## 👮 管理员功能

仅管理员登录可见：

- **设置**：下载目录（服务器本地路径）、并发数 1–10、**本地文件保留时长**（首次启动默认 1 小时，可选 30 分钟 / 1 小时 / 24 小时 / 7 天）、**单次下载总量上限**（MB，0=不限制）、**磁盘预留空间**（MB，默认 1024，0=不预留）；
- **邀请码管理**：批量生成、查看（未用/已用）、删除；
- **在线统计**：当前在线用户数、正在下载人数;
- **磁盘监控**：管理页显示已用/剩余空间；可用空间不足时显示警告。

普通用户看不到上述入口，直接调对应 API 返回 403。

## ⚠️ 注意事项

1. **仅限可信内网/个人自用**：建议自行搭建部署使用，公网暴露要自担风险（建议加 VPN/防火墙白名单，或搭在 Tailscale 内网）；
2. **夸克 Cookie 是敏感凭据**：虽然只存浏览器、不落服务器，但在你设备上可用的等效于你本人网盘权；不要把浏览器 Cookie 教程中的内容额外复制给他人；
3. **接口风控不可控**：夸克可能不定期调整接口/限流策略；遇到解析、转存失败请稍后再试或更新夸克 Cookie。
4. **网络环境**：夸克为国内直连服务，本项目已**强制绕过系统/环境代理**（`trust_env=False`）。如果你启用了全局 VPN，夸克流量仍会直连；请确保服务器与夸克接口连通。
5. **磁盘空间**：默认「本地文件保留」为 **1 小时**（管理员可在 30 分钟 / 1 小时 / 24 小时 / 7 天中选择）；后台每 10 分钟按冻结的到期时刻清扫，空文件夹一并收拢，未完成下载的 `.part` 在取消、失败过期或服务启动时回收。管理员可设置**磁盘预留空间**（默认 1 GB），可用空间不足时新下载任务排队并显示警告，空间释放后自动继续。
6. **多文件打包下载**：勾选多个文件/目录时完成项走 **ZIP 打包**一次下载（不压缩重复压多媒体，省 CPU）；单文件仍是直接下载。
7. **网盘临时目录**：转存使用网盘内 `QuickPandownTemp/`，服务器启动时会自动清空该目录（残留兜底），也可手动删除。
8. **数据备份**：四个文件——`data/db.json`、`data/settings.json`、`data/tasks.json`、`data/secret.key`（加数据库本身）。
9. **数据库凭据在 `data/db.json`**：首次模板默认 SQLite。启用 MySQL 需要手动配置该文件。
10. **验证码与限速**：注册/登录的验证码为服务端一次一换（TTL 5 分钟）；连续登录失败会触发指数退避锁定。

## ❓ 常见问题

**Q: 打开页面一直跳登录页？**

你没有登录，或会话已过期（7 天 TTL）。登录即可。

**Q: 解析提示「Cookie 无效，请重新复制」？**

浏览器里的夸克 Cookie 失效了，重新登录夸克网页版再点【Cookie 徽章】粘贴。

**Q: 展开目录 / 下载提示「分享需要提取码，或提取码错误」？**

前端已自动携带你输入过的提取码。若仍复现，多数是**粘贴的原始文本里多条链接**或提取码粘错——单独贴这一条链接与提取码再试。

**Q: 任务一直「队列中」不动？**

检查管理员设置里的并发数是否被占满、该用户的夸克 Cookie 是否有效；失败项自动给出原因（如 ConnectTimeout = 网络问题）。

**Q: 任务提示「磁盘空间不足」并一直排队？**

服务器可用空间已低于管理员设置的预留值，新任务会等待空间释放后自动开始。可等待保留期清扫旧文件，或让管理员清理 `downloads/`、调小预留空间。

**Q: 重试提示「任务已随服务重启失效，请重新提交下载」？**

服务重启会清空引擎内存里的重试上下文，历史任务无法原地重试；重新解析分享并提交即可。这是有意设计，用于替代以前误导性的「任务不存在」。

**Q: 提交下载提示「超过单次下载上限 NMB」？**

管理员设置了总量上限，按勾选文件大小总和计算（目录按已展开叶子累计）。减少勾选，或让管理员调大/清零上限。

**Q: 点下载提示「文件已过期，请重新下载」？**

浏览器点下载前，前端会先校验有效期、服务器会先校验文件真实存在，文件超过管理员设置的保留时长会被后台清理。请在任务卡上重试或重新把分享提交为下载任务。

**Q: 提示端口占用？**

8756 被（或其他 QuickPandown 实例）占用，改 `run.py` 的 `PORT`。

**Q: 数据库连接失败？**

优先检查 `data/db.json` 里的 `db_url`（或环境变量 `QP_DB_URL`，优先级更高）：实例可达、用户名密码正确、库名存在（MySQL 无库时启动会自动尝试建库）。改完配置重启服务生效。
